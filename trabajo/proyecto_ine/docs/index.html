1 Introducción

Este informe documenta una solución ETL local para transformar la base anual 2025 de la Encuesta Nacional de Empleo (ENE) en indicadores laborales consultables. El documento es reproducible: cada paso contiene el código que se ejecuta y el botón de copia de Quarto permite reutilizarlo directamente.

La base original no se incorpora al repositorio por su tamaño. Para reproducir el análisis, se descarga la base anual ENE desde el INE y se ubica como data/raw/ano-2025.csv.

2 1. Arquitectura y dataset utilizado

2.1 1.1 Componentes de la solución

flowchart LR
  A[Base anual ENE 2025<br/>CSV] --> B[Extracción<br/>src/extraer.py]
  B --> C[Transformación y calidad<br/>src/transformar.py]
  C --> D[Carga<br/>src/cargar.py]
  D --> E[SQLite, CSV y Parquet]
  E --> F[Dashboard Streamlit y HTML]

El proceso usa pandas y numpy para el tratamiento de datos, SQLite como repositorio analítico local y Streamlit para la visualización interactiva. La carga a Amazon S3 es opcional y queda desactivada por defecto.

2.2 1.2 Características de la fuente

Atributo Descripción
Origen Instituto Nacional de Estadísticas de Chile, Encuesta Nacional de Empleo.
Archivo data/raw/ano-2025.csv
Formato CSV UTF-8, separado por ; y con decimal ,.
Frecuencia Anual.
Volumen procesado 390.903 registros, 222 columnas y 146,42 MB.
Unidad de análisis Persona integrante de un hogar encuestado.

El pipeline utiliza las variables ano_trimestre, region, sexo, edad, cae_especifico, ocup_form, sector, habituales, c10, c11, e4 y fact_anual. El factor anual expande los registros de la muestra a una estimación de personas.

2.3 1.3 Preparación reproducible

Desde la carpeta raíz del proyecto, ejecute una vez lo siguiente. En Windows, si Quarto no está instalado, instálelo desde https://quarto.org antes de renderizar el informe.

python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
quarto render informe.qmd

La primera ejecución genera este mismo documento en docs/index.html; esa es la carpeta que se publica en GitHub Pages.

El siguiente archivo controla la fuente, las reglas de población en edad de trabajar, el destino de resultados y la conexión opcional a AWS.

from src.cargar import subir_a_s3

)
